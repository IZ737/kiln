# Getting help with Kiln

Kiln is a pre-1.0 project maintained on a best-effort basis. Issues are welcome, but there is no guaranteed response time or paid support service.

## First steps

- **Getting started:** [README](README.md) and the [examples](examples/).
- **Language syntax, modules, Glazes and stdlib:** [documentation index](docs/README.md).
- **Editor integration and LSP:** [editor guide](docs/guides/editors.md).
- **Implemented vs planned features:** [roadmap](README.md#roadmap) and [plans](docs/README.md#implementation-plans).
- **Installers and binaries:** [releases](https://github.com/IZ737/kiln/releases).

## Where to ask

- **Reproducible bug:** [open a bug report](https://github.com/IZ737/kiln/issues/new/choose). Include the Kiln version or commit, platform, a minimal `.kiln`/`.glaze`/`.ember` example, the command run, and expected versus actual results.
- **Question or usage confusion:** search [existing issues](https://github.com/IZ737/kiln/issues) first. If the docs do not answer it, open a concise issue describing what you are trying to do. Questions that reveal a documentation gap are useful.
- **Feature or language design suggestion:** start with the [feature request form](https://github.com/IZ737/kiln/issues/new/choose) and explain the problem before proposing syntax.
- **Possible security problem:** follow [SECURITY.md](SECURITY.md) and **do not** publish details in an issue.
- **Community conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For contribution instructions, see [CONTRIBUTING.md](CONTRIBUTING.md).
